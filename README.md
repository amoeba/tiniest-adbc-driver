# tiniest-adbc-driver

[![CI](https://github.com/amoeba/tiniest-adbc-driver/actions/workflows/ci.yml/badge.svg)](https://github.com/amoeba/tiniest-adbc-driver/actions/workflows/ci.yml)

The tiniest [ADBC](https://arrow.apache.org/adbc) driver, written as a literate C program.
See https://amoeba.github.io/tiniest-adbc-driver/ for rendered output.

## Building

```sh
make
```

## Testing

With `uv`,

```sh
uv run pytest
```
